# buzdolabi-kapisi-kapaliyken-isigin-durumu-milli-istihbarat-teskilati
Buzdolabı kapağı kapanınca içerdeki ışığın sönüp sönmediğini resmi istihbarat sorunu, milli soğukluk egemenliği ihlali ve gözlem protokolü sapması sayan; rafı dinleme cihazı, 'kapıyı bir aralayayım' cümlesini operasyon emri ilan eden Teşkilat. Gerçekten çalışır. Işıklar artık ajan dır.
