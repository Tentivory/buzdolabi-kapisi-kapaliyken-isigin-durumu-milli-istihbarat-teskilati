# Milli İstihbarat Teşkilatı
## Buzdolabı Kapağı Kapalıyken Işığın Durumu Gözlem Dairesi

> Kapı kapanınca içerisi karanlık mı kalır, yoksa lamba vatan görevine devam mı eder?
> Bu soru yüzyıllardır bilim tarafından değil, mutfak tarafından sorulmaktadır.

Bu yazılım, buzdolabı kapağının kapanmasını **resmi istihbarat boşluğu**, içerideki ampulü **milli soğukluk egemenliği unsuru**, "bir aralayayım bakayım" cümlesini ise **operasyon emri** sayar.

Gerçekten çalışır. Işıklar artık ajandır.

## Kurulum

```bash
python3 mit_buzdolabi.py
```

Bağımlılık yoktur. Teşkilat kendi kendine yeter.

## Ne yapar?

- Kapıyı rastgele açık, aralık, kapalı veya "sanıyorum kapalı" kabul eder.
- Işık durumunu resmi rapor formatında yazar.
- Kapı kapalıysa güven puanını dürüstçe düşürür. Çünkü **görmediğin şeyi teyit edemezsin**.
- Beş operasyonluk günlük brifing basar.

## Bilimsel dayanak

Yoktur. Var gibi durur. Bu yeter.

Ampul üreticilerinin "kapı kapanınca söner" iddiası Teşkilat tarafından **kaynak belirtilmeden kabul edilmiş saha söylentisi** olarak işlenmiştir.

## Sık sorulan sorular

**Işık gerçekten sönüyor mu?**  
Kapıyı açarsan görürsün. Açmazsan bu repo senin yerini tutmaz.

**Neden MİT?**  
Çünkü evdeki en kapalı kutu buzdolabıdır. İçini bilmek isteyen herkes bir gün Teşkilat olur.

**Patates var mı?**  
Yok. Rafın sağında olmayabilir. Solunda da.
